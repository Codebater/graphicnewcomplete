Install

  1. Gmail: Settings → See all settings → General → Signature → Create new → paste (Ctrl/Cmd+V) → Save changes.
  2. Apple Mail: Settings → Signatures → + → paste. Untick “Always match my default message font”.
  3. Outlook (web/new): Settings → Account → Signatures → paste. Classic desktop Outlook shows the first GIF frame only.
  4. If a client refuses the paste, select the card above manually (click-drag from its top-left to bottom-right), copy, and paste.
